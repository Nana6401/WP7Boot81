# WP7Boot81
Windows phone 8.1 on Windows phone 7.X (unfortunatly vibecoded)

PROJECT IS COMPLETLY RENOVATED WITH A NEW APPROACH

This project aims at Porting the Windows Phone 7.X Bootloader to Windows phone 8.1 to work on a vast majority of Windows 7 Phones.

Currently done :

- Locating the bootloader - DONE
- Mapping Bootloader - DONE
- Extracting FFU Files - DONE
- Porting - Doing
- Booting - Doing
- Driver Porting - NOT DONE

Currently reaching : 846.87 million estimated kernel instructions

Be warned that when this first release it will be very unstable and may brick your device . Proceed with caution
